# Founder story — TideGuard AI

> Template. Replace each `[…]` with first-person details before submission.

I grew up on a beach in [city]. By age 10, I learned that the brightly colored bottles I collected each summer were not lost cargo — they were everyone else's litter, carried by the current to my doorstep. Some bottles had Chinese characters, some Korean, some Vietnamese. The ocean had no border, but the responsibility for what arrived on our shore fell on us.

When I was 13, I joined my first organized cleanup. We collected 200 kg of plastic in a morning. Three weeks later the same beach looked the same. I asked the organizer, "if we know this happens every month, why do we always show up too late?" She said, "because nobody predicts it."

That sentence stuck with me.

A year later, I started learning Python in a free online course. I read about Raissi et al.'s **Physics-Informed Neural Networks** in 2023, and realised the same math used to predict heat in materials or fluid in pipes could predict marine debris — *if we had the data*. We did: Copernicus and ERA5 are free. The missing ingredient was a system that could combine satellite forecasts with what local people actually see on the ground, and then turn predictions into action.

So I built TideGuard.

I built it open-source because the kids on the next beach over deserve the same tools. I built the education module because the only sustainable solution is a generation that doesn't see "plastic in the ocean" as normal. I built the leaderboard because a 12-year-old will run three cleanups if her school sees the number tick up.

This is not a research project. It's a working tool with a real first pilot at [school name]. Every line of code in this repository is intended to be deployed, used, and improved upon by the next student who picks up the torch.

— [Founder name]
